# Production Fact Checklist

Complete before counsel review and again before launch.

```text
[ ] Exact Bidwright SHA deployed
[ ] Bidwright license identifier confirmed from deployed source
[ ] All Bidwright modifications listed
[ ] Deployment containers/processes listed
[ ] Network routes documented
[ ] Public endpoints documented
[ ] Tenant/user access documented
[ ] Operator/admin Bidwright access documented
[ ] Source-code availability mechanism documented if required
[ ] Notices/attribution mechanism documented if required
[ ] Container image/distribution model documented
[ ] Customer-hosting model documented
[ ] Legal review decision attached
[ ] Engineering release gate updated with decision
```
